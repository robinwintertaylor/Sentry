# Avatars

`sentry.png` is the default — a geometric "watch" mark: an arc held open
over a fixed point. Watching, not acting.

Two variants ship so Sentry matches whichever pack it sits beside:

- `sentry-work.png` — the austere instrument mark (default)
- `sentry-home.png` — the friendlier character, for the Hearth-style set

To switch, copy the one you want over `sentry.png` and re-run the
snapshot generator.
